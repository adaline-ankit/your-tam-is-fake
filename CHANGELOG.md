# Changelog

## 0.1.0

First release.

- Core skill: six-phase loop (interrogate → research → size → steelman → attack → verdict) and twelve non-negotiables.
- Three intensity levels (`lite` / `spicy` / `nuclear`) that change prose only, never analysis.
- Anti-sycophancy mechanics: forbidden validation openers, the two-legitimate-reasons rule for changing a conclusion, the disagreement register, and mandatory confidence labels.
- Anti-contrarianism guard: research and a steelman are required before any attack.
- Ten reference files covering market sizing, research protocol, ICP and wedge, GTM motions, pricing and unit economics, channels, red flags, benchmarks, output format, and pop-culture usage.
- Packaging for Claude Code, Codex, Cursor, Gemini CLI, and a self-contained `AGENTS.md`.
- Eval suite with rubric.

## 0.2.0

Research depth and a multi-hour working mode.

- **Deep mode** (`/your-tam-is-fake deep`): eight workstreams with exit criteria, run over hours, writing a directory of deliverables. Append-only research log makes it resumable across sessions. Saturation rule (three consecutive empty searches) replaces open-ended searching. Contradiction ledger forces disagreeing sources to be resolved explicitly or left unresolved with a widened range. Five-angle self-critique pass before any verdict, including a check for whether the conclusion matches what the user hoped for.
- **Depth is now independent of intensity** — `quick` / `standard` / `deep` control work done; `lite` / `spicy` / `nuclear` control voice only.
- **Eight new reference files**: framework index, deep-research protocol, customer research (Mom Test, Four Forces, win/loss), PMF measurement, positioning and narrative, sales process and capacity modelling, data sources, and AI-era GTM.
- **Three new non-negotiables**: frameworks structure evidence rather than substituting for it; diagnose PMF before diagnosing GTM; ship artifacts as files rather than walls of text.
- **`assets/deck-template.html`** — self-contained, print-to-PDF deck scaffold with source-tier tags built in.
- **Benchmarks expanded** with sales ramp and attainment by segment, buying-committee size, cycle length by ACV band, AI-era discovery data, and category economics. All dated and sourced.
- Evals grown from 20 to 32 cases, covering PMF misdiagnosis, framework theatre, capacity fantasy, stale playbooks, attribution errors, anxiety-blindness, category creation, and deep-mode protocol adherence.
